# Homebrew Tap for Gox

Official Homebrew tap for [Gox](https://tuyennq1001.github.io/gox/) — Native Vietnamese & Japanese dual input engine for macOS with JIS keyboard support, zero underline, and Secure Input visual alert.

## Installation

```bash
brew install --cask tuyennq1001/tap/gox
```

Or tap first and then install:

```bash
brew tap tuyennq1001/tap
brew install --cask gox
```

## Update

```bash
brew upgrade --cask gox
```

*(Note: Gox also supports 1-click in-app auto updates directly from the Menu Bar!)*

## Uninstall

```bash
brew uninstall --cask --zap gox
```
